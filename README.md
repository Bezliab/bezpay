# BezPay

Starter project structure for a React + Vite client and Node.js + Express server.

## Structure
- `client/` — frontend application
- `server/` — backend API, Monnify integrations, jobs, repositories, and SQL schema

## Getting started

Install dependencies separately in `client/` and `server/`. Copy each `.env.example` to `.env` and configure your local credentials.

> This is a scaffold: most modules contain TODO placeholders and are not yet a working payment application. Add and test authentication, validation, database migrations, Monnify integration, webhook signature verification, idempotency, and transaction state handling before using real funds.
